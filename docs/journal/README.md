# Engineering Journal (엔지니어링 저널)

Lunéa를 만들며 마주친 문제를 **어떤 선택지 중에서, 어떤 제약 때문에, 어떻게 결정했는지** 이야기 형식으로 남깁니다. 포트폴리오와 기술 명세의 근거로 사용합니다.

- 공식 결정 1건의 요약은 `docs/adr/`, 실수와 재발 방지는 `docs/lessons/`, 현재 상태는 `docs/STATUS.md`.
- 작성: `/lunea-log "주제"` 또는 작업 마무리(`/lunea-finish`) 시 결정이 있었던 경우.
- 사실만 씁니다. PR·커밋·ADR·Jira를 근거로 링크하고, 불확실한 내용은 불확실하다고 표시합니다.
- 초안은 에이전트가 쓰고, 최종 문장은 제품 책임자가 다듬습니다.

## 템플릿
```md
# 제목
- 날짜 / 관련: LUN-xx, PR #N, ADR-000N
## 배경
## 고려한 선택지
| 선택지 | 장점 | 단점 | 비용 |
## 결정과 이유
## 진행 중 생긴 문제와 대응
## 결과
## 회고 (나중에 추가)
```

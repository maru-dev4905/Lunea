# 핵심 화면 와이어프레임(UX-01): 구조는 그리되 비교할 지점만 표시하기
- 날짜 / 관련: LUN-14 (UX-01), D-12, D-14, D-15, D-36, D-37, `docs/03a_WIREFRAMES.md`

## 배경
Today, 쓰기, 감정 검토, 저장, Collection, 상세, 설정 화면의 저충실도 흐름이 필요했습니다. 제약은 문서만 다룰 것(앱 코드·의존성 없음), 영수증 은유는 임시(D-12)이고 가격·연속 기록은 영수증 안에서만(D-37), UI에 배경 채움 없음(D-36)이었습니다.

## 고려한 선택지
| 선택지 | 장점 | 단점 | 비용 |
|---|---|---|---|
| 별도 파일 `docs/03a_WIREFRAMES.md` + docs/03에 링크 | docs/03의 동작 명세가 짧게 유지되고, 와이어프레임만 따로 바뀜 | 두 문서를 같이 맞춰야 함 | 낮음 |
| docs/03 안에 와이어프레임 삽입 | 한 문서 | docs/03이 길어지고 일관성 검사 대상 구간이 흔들림 | 낮음 |
| Figma 등 외부 도구 | 시각적으로 풍부함 | diff가 안 되고 접근·권한이 따로 필요함 | 높음 |

## 결정과 이유
- 별도 파일에 ASCII와 Mermaid로 작성. GitHub에서 그대로 렌더링되고 diff가 됨.
- 선(`+ - |`)만 사용해 D-36(배경 채움 없음)을 와이어프레임에도 적용.
- 영수증은 "Collection"이라는 중립 이름을 쓰고, 상세 화면의 "Receipt view" 링크 한 곳에만 임시(PROVISIONAL)로 표시. 지울 수 있게 분리.
- 비교형 대상은 감정 검토와 저장 피드백. 변형 시안은 그리지 않고, "무엇이 달라질 수 있는지" 축만 적음.
- 감정 크기(D-37 항목 2)를 감정 검토 단계에서 물을지 영수증 모듈에서 물을지는 정해지지 않아 그리지 않고 미정으로 남김.
- 정해지지 않은 것(D-11, D-13, D-14, D-16, D-17, D-20, 페이지네이션 방식, 강도 척도)은 새로 정하지 않고 TBD로 표시.

# Codex 없이 독립 리뷰 체계 만들기
- 날짜: 2026-11-11 / 관련: PR #2, D-21, L-003, L-005

## 배경
기획은 "Claude가 구현, Codex가 독립 리뷰"를 전제로 했다. 확인해 보니 Codex의 GitHub PR 리뷰는 ChatGPT 무료 플랜에서 제공되지 않았다(Plus 이상 필요).

## 고려한 선택지
| 선택지 | 장점 | 단점 | 비용 |
|---|---|---|---|
| Codex 유료 결제 후 그대로 진행 | 기획 그대로 | 앱 코드가 없는 초기에 비용 대비 효과 낮음 | 월 구독 |
| **CodeRabbit만 사용** | 다른 회사 AI라 독립성 높음, GitHub App이라 설정 간단 | 비공개 저장소 요금 조건 불확실 | 플랜에 따름 |
| Claude가 별도 세션으로 자체 리뷰 | 추가 비용 없음 | 같은 모델 계열이라 맹점 공유 | 0 |

## 결정과 이유
CodeRabbit을 유일한 외부 리뷰어로 두고, Codex는 기능 개발 시작 시 유료 플랜과 함께 추가하기로 했다(D-21). `CODEX_REVIEW.md`는 삭제하지 않고 모든 리뷰어 공통 기준으로 유지했다. 리뷰 언어는 `ko-KR`로 설정했고, PR·커밋 본문을 국문으로 쓰는 규칙을 `CLAUDE.md`에 추가했다.

## 진행 중 생긴 문제와 대응
- CodeRabbit이 Codex 도입 조건이 문서마다 다르다고 지적 → 제품 책임자 결정으로 "FND-02 시작 시 유료 플랜 도입"으로 통일.
- 단위 테스트 자동 생성 기능이 PR 브랜치에 Python 테스트를 직접 커밋(L-003) → `git revert`로 되돌리고 설정에서 기능을 끔.
- 리뷰 봇이 이전 커밋 기준으로 답하는 시점 차이(L-005).

## 결과
PR #2 merge. CodeRabbit 리뷰가 국문으로 동작함을 확인. merge 위험도 Minimal.

# 프로젝트 상태

**이 문서는 국문으로 씁니다.** 제품 책임자가 "AI가 지금 프로젝트를 어디까지 이해하고 있는지" 확인하는 문서이기 때문입니다. 에이전트는 세션 시작 시 이 문서를 읽고, 작업을 마칠 때(`/lunea-finish`) 갱신합니다. 짧고 최신으로 유지하고, 지난 기록은 `docs/journal/`에 남깁니다.

마지막 갱신: 2026-11-18 (LUN-14 와이어프레임, LUN-36 조율자 한 줄 명령, 모드 C 첫 시범 운영)

## 단계
Foundation(기반). 기획 문서, 기술 결정(ADR), 에이전트 작업 체계가 갖춰졌고, `apps/mobile`에 Expo 앱 뼈대(탭 3개 placeholder, 테마 토큰, 웹·앱 지원)와 실제 CI 검사, `supabase/`에 PoC(RLS, Edge Function, 로컬 테스트)가 `dev`에 들어갔습니다. PoC 조건 3·5가 사람 확인 대기라 ADR-0002는 아직 확정되지 않았습니다. 기능은 일기 초안 작성기(메모리 내 초안, 저장은 아직 연결되지 않음)와 영수증 프로토타입(가짜 데이터)까지만 `dev`에 있고, 저장·목록·AI·인증은 아직 없습니다.
